# Rutherford's Functions
A set of various number providers which provide common math functions. Trig, inverse trig, hyperbolics, natural logarithm, and gamma. 

All function inputs are under the relevant storage names and input paths, which can be replaced for your needs using any text/code editor of preference:

All trigonometric and inverse functions (including hyperbolic versions) have their storage as "trig.math" and path as "input". However, `atan2` uses "x" and "y" as the inputs.

Natural logarithm `ln` has its storage as "ln.math" and path as "input".

Gamma function `gamma` has its storage as "gamma.math" and path as "input".
